Implementation**\n\n### **Database Security:**\n```sql\n-- Only verified therapists can insert scenarios\nCREATE POLICY \"Allow verified therapists to insert scenarios\" \nON training_scenarios FOR INSERT WITH CHECK (\n  EXISTS (\n    SELECT 1 FROM user_roles \n    WHERE user_id = auth.uid() \n    AND role IN ('therapist', 'admin')\n    AND verified = TRUE\n  )\n);\n```\n\n### **App-Level status = 'approved', reviewed_at = NOW()\nWHERE user_id = '[user-id]';\n```\n\n### **Track Usage:**\n```sql\n-- See how many verified therapists you have\nSELECT role, verified, COUNT(*) \nFROM
