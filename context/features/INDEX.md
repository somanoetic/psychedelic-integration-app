## Prioritization Framework

Features are prioritized based on:
1. **User Impact** - How many users benefit?
2. **Strategic Value** - Core differentiator or table stakes?
3. **Effort** - How long to build?
4. **Dependencies** - Blocks other features?
5. **Risk** - Technical or market risk?

**Formula:** (Impact × Strategy) / (Effort × Risk)

## Feature Lifecycle

```
Idea → Planned → In Progress → Complete → Archive
  ↓       ↓          ↓
Rejected  Deferred   Blocked
```

**Lifecycle Rules:**
- Ideas can be rejected (documented in ideas.md)
- Planned can be deferred back to ideas
- In Progress can be blocked (escalate immediately)
- Completed features archived after 30 days

## How to Use

### Proposing a New Feature
1. Add to `ideas.md` with full template
2. Present in weekly planning
3. Team decides: plan, defer, or reject
4. If planned, move to `planned.md` with target phase

### Starting a Feature
1. Move from `planned.md` to `in-progress.md`
2. Assign developer
3. Create detailed implementation plan
4. Update weekly with progress

### Completing a Feature
1. Mark as complete in `in-progress.md`
2. Document in changelog
3. Remove from tracking files after 30 days
4. Celebrate! 🎉
