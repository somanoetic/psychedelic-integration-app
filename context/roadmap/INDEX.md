## Roadmap Philosophy

**Focus on Short-Term:**
- Detailed plans only for next 4 weeks
- Next phase has broad strokes
- Future is intentionally vague

**Why?**
- Plans change based on learnings
- User feedback shapes priorities
- Stay agile and responsive

**Avoid:**
- Over-planning months ahead
- Committing to distant features
- Rigid timelines
