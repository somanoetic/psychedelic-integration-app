useSessionChecklist.js (Custom Hook - State Management)
========================================================

Hook Functions:
├── loadChecklist()           → Load from cache + database
├── toggleItem(itemId)        → Optimistic toggle with rollback
├── addItem(itemData)         → Optimistic add with rollback
├── updateItem(itemId, data)  → Optimistic update with rollback
└── deleteItem(itemId)        → Optimistic delete with rollback

Hook State:
├── checklist                 → Full checklist object with items
├── loading                   → Initial load state
├── error                     → Error message (if any)
├── syncing                   → Currently syncing to database
└── offline                   → Offline mode indicator

AsyncStorage Cache:
└── checklist_{sessionId}     → Cached checklist for offline/instant load


Backend Service (lib/sessionChecklistService.js)
=================================================

Service Methods:
├── getOrCreateChecklist(sessionId)
├── toggleItemCompletion(itemId, isCompleted)
├── addCustomItem(checklistId, itemData)
├── updateItem(itemId, updates)
└── deleteItem(itemId)

Database Tables:
├── session_checklists
│   └── id, session_id, total_items, completed_items, completed_at
├── session_checklist_items
│   └── id, checklist_id, title, description, category, is_checked, is_custom
└── checklist_template_items
    └── Default 18 items template


Data Flow
=========

User Action → Optimistic UI Update → Cache Update → Database Sync
                                                           │
                                                    Success ↓
                                         Update with fresh data
                                                           │
                                                    Error  ↓
                                         Rollback to previous state


Category Types
==============

1. Physical Preparation (fitness-center icon, primary color)
   - Fasting, hydration, sleep, healthy meals, avoid alcohol

2. Safety & Support (shield icon, warning color)
   - Sitter, trusted person, emergency contacts, harm reduction

3. Mental/Emotional (spa icon, sage color)
   - Intentions, journaling, meditation, release expectations

4. Practical Logistics (checklist icon, slate color)
   - Safe space, supplies, music, notifications off, clear schedule
