================================================================================
  ROLLBACK PROCEDURES
================================================================================

QUICK ROLLBACK (< 5 minutes):
1. Code rollback:
   - git revert --no-edit HEAD
   - eas build --platform all --auto-submit

2. Feature disable (graceful):
   - Set METRICS_ENABLED = false in App.js
   - Rebuild without database changes

FULL ROLLBACK (5-15 minutes):
1. Supabase backup restore (recommended):
   - Log in to Supabase dashboard
   - Settings > Database > Backups
   - Click "Restore" on pre-deployment backup

2. Manual SQL rollback:
   - psql ... -f deployment/rollback.sql
