## 🔧 Troubleshooting

### **If Claude isn't responding:**
- Check your `ANTHROPIC_API_KEY` in `.env`
- Ensure you have internet connection
- Check console logs for API errors

### **If practices aren't appearing:**
- Practices trigger based on nervous system state
- Try selecting higher activation levels (7+/10)
- Check that practice widgets aren't blocked

### **If entities aren't extracting:**
- Use rich descriptive language about emotions, symbols, body sensations
- Mention archetypal imagery (animals, nature, wise figures)
