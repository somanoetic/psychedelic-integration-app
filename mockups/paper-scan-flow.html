Design notes

Free-form variant (not pictured)

When the user scans a page with no glyph, the Review screen falls back to: (a) a worksheet picker at the top — "Which page is this?" with options + "Free-form page", and (b) if free-form, a single Transcription block instead of named fields, plus a Thematic notes block underneath with light observations about parts/body/themes. Honors the no-judgment-snapshot pattern.

Glyph behavior

  • Small mark (~14–18px on the printed page), bottom-right corner.
  • Encodes MT-{worksheet-id}-v{n}. Versioned so changing a worksheet doesn't break older scans.
  • Same mark in the in-app PDF generator and on pages of the future purchased journal.
  • If Claude can't read the glyph (cut off, smudged, taken from old printout) → fall back to manual worksheet picker.

Edit-transcription affordance

Tapping any field's "Edit transcription" link opens an inline editor with the raw Claude output. User can correct misreads before saving. Corrected values are what get persisted + sent to the therapist. The original image is always kept untouched alongside.

Therapist-share toggle

Default ON (sage chip with check). Tapping it once flips to "Private" — single-tap opt-out per scan. No dialog, no friction. Chip color shifts to muted gray when off.

What's net-new in the codebase

  • New dependencies: expo-camera, expo-image-manipulator, a doc-scanner (e.g. react-native-document-scanner-plugin), expo-print for PDF generation. Requires a dev build — not Expo Go.
  • New Supabase Storage bucket: paper-scans with per-user RLS.
  • New entry type in journal/session schema (type='paper_scan' + image_storage_path + worksheet_id + transcription_json + thematic_notes).
  • New worksheet config directory: content/worksheets/*.js.
  • New mode in lib/huxleyService.js: paper_scan_interpretation.
  • Vision message support added to lib/claudeProxyService.js and its edge function.

Out of scope for v1

  • Multi-page scans (one image = one entry for now).
  • OCR-style searchable transcript across all scans (defer until library grows).
  • "Reflect with Huxley" deep-dive on a scan — surfaced as an action button but the actual conversational flow reuses existing Huxley modes; no new conversational work for v1.
