# 🎯 **How to Access Training Scenarios**\n\n## 📱 **Option 1: In-App Upload Interface (Recommended)**\n\n### **Access Path:**\n```\n🎓 Education Tab → Advanced Training → Upload Training Scenarios\n```\n\n### **Features:**\n- ✅ **Upload both JSON and text formats**\n- ✅ **Load example data** with one click\n- ✅ **Format validation** and error handling\n- ✅ **Success confirmation** with count of uploaded scenarios\n- ✅ **Example templates** built-in\n\n### **How to Use:**\n1. **Go to Education tab** in your app\n2. **Tap \"Upload Training Scenarios\"** in the Advanced Training section\n3. **Choose format** (Text or JSON)\n4. **Load example data** or paste your own scenarios\n5. **Upload** and get confirmation\n\n---\n\n## 🗄️ **Option 2: Direct Database Access (Supabase)**\n\n### **Access Path:**\n```\nSupabase Dashboard → Your Project → Table Editor → training_scenarios\n```\n\n### **What You Can Do:**\n- ✅ **View all scenarios** in a table format\n- ✅ **Edit existing scenarios** directly\n- ✅ **Delete scenarios** you don't want\n- ✅ **Add new scenarios** manually\n- ✅ **Export scenarios** for backup\n- ✅ **See usage statistics** from scenario_usage table\n\n### **Useful Database Views:**\n```sql\n-- See all scenarios by category\nSELECT category, COUNT(*) as count \nFROM training_scenarios \nGROUP BY category;\n\n-- See most recent scenarios\nSELECT * FROM training_scenarios \nORDER BY created_at DESC \nLIMIT 10;\n\n-- Find scenarios by trigger words\nSELECT * FROM training_scenarios \nWHERE 'shadow' = ANY(triggers);\n```\n\n---\n\n## 📊 **Option 3: Using Pre-Built Example Files**\n\n### **JSON Format Example:**\n**File:** `training-data/example_scenarios.json`\n```json\n{\n  \"difficult_visions\": {\n    \"triggers\": [\"dark\", \"scary\", \"shadow\"],\n    \"examples\": [{\n      \"userMessage\": \"I saw terrifying shadow figures...\",\n      \"goodResponse\": \"Thank you for sharing something so vulnerable...\",\n      \"approach\": \"validate_first_then_regulate\"\n    }]\n  }\n}\n```\n\n### **Text Format Example:**\n**File:** `training-data/example_scenarios.txt`\n```\nUSER: I saw dark shadow figures that felt threatening\nCLAUDE: Thank you for sharing something so vulnerable...\nAPPROACH: validate_first_then_regulate\nTRIGGERS: dark, shadow, threatening, scary\nNOTES: Shadow work requires extra safety\n\n---\n\nUSER: I felt connected to everything\nCLAUDE: What a profound experience...\n```\n\n---\n\n## 🔄 **Option 4: Monitoring & Analytics**\n\n### **Track Usage:**\n```sql\n-- See which scenarios Claude uses most\nSELECT s.category, s.user_message, COUNT(u.id) as usage_count\nFROM training_scenarios s\nJOIN scenario_usage u ON s.id = u.scenario_id\nGROUP BY s.id, s.category, s.user_message\nORDER BY usage_count DESC;\n```\n\n### **Effectiveness Tracking:**\n```sql\n-- See average ratings for scenarios\nSELECT s.category, AVG(u.user_rating) as avg_rating\nFROM training_scenarios s\nJOIN scenario_usage u ON s.id = u.scenario_id\nWHERE u.user_rating IS NOT NULL\nGROUP BY s.category;\n```\n\n---\n\n## 🎯 **Current Categories Available:**\n\n1. **👁️‍🗨️
